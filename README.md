# Syscripts

> A collection of my scripts for everyday use, automation, and experiments.

This repository contains my personal collection of scripts written in:

* **Bash**
* **PowerShell**
* **JavaScript**
* **Python**

The scripts cover different tasks, from small utilities and system automation to random experiments and things I find useful.

## Usage

Clone the repository:

```bash
git clone https://github.com/shizi-x/syscripts.git
cd syscripts
```

### Bash

Make it executable:

```bash
chmod +x script.sh
./script.sh
```

### PowerShell

```powershell
pwsh script.ps1
```

### JavaScript

```bash
node script.js
```

### Python

```bash
python3 script.py
```
